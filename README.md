# Netflix Analytics

## Project Overview

This project analyzes movie data to identify trends, patterns, and insights using Python. The analysis focuses on movie genres, release years, vote averages, and popularity categories through data cleaning, data transformation, exploratory data analysis, and visualization.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
* Data Visualization

## Project Workflow

1. Loaded and inspected the movie dataset
2. Cleaned and prepared the data for analysis
3. Converted data types and removed unnecessary columns
4. Performed Exploratory Data Analysis (EDA)
5. Created custom categories based on vote averages
6. Analyzed movie genres and release year distributions
7. Identified patterns in movie popularity and ratings
8. Created visualizations using Matplotlib and Seaborn
9. Interpreted the results and generated insights

## Files

* `netflix analysis.ipynb` — Python analysis, data cleaning, EDA, and visualizations
* `mymoviedb.csv` — Movie dataset used for the analysis
* `movie data analysis project ppt.pptx` — Project presentation and analysis findings
