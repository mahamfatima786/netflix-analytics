# Movie Analytics

## Project Overview

This project analyzes movie data to identify trends, patterns, and insights using Python. The analysis focuses on movie genres, release years, vote averages, and popularity categories through data cleaning, transformation, exploratory data analysis, and visualization.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
* Data Visualization

## Project Workflow

1. Loaded and inspected the movie dataset
2. Cleaned and prepared the data for analysis
3. Converted data types and removed unnecessary columns
4. Performed exploratory data analysis (EDA)
5. Created custom categories based on vote averages
6. Analyzed movie genres, release years, and popularity
7. Created visualizations using Matplotlib and Seaborn
8. Interpreted the results and generated insights

## Files

* `movie_analysis.ipynb` — Python analysis, EDA, and visualizations
* `movies.csv` — Movie dataset
* `presentation` — Project presentation

Python | Pandas | NumPy | Data Cleaning | Data Transformation | EDA | Data Analysis | Matplotlib | Seaborn | Data Visualization
